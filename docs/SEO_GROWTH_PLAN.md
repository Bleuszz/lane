## Search findings

Inventory searches also surfaced [Sellganise](https://www.sellganise.com/) and [UpTrend](https://up-trend.co.uk/), so generic “inventory software” is wider than crosslisting. These are existence/content observations, not rankings or endorsement.

An actual [FlippingUK discussion](https://www.reddit.com/r/FlippingUK/) titled “Vinted to Ebay” concerns **buying on Vinted to resell**, demonstrating that the phrase alone is ambiguous. Paid terms must include listing/crosslisting/software intent. [UK crosslisting discussion](https://www.reddit.com/r/ebayuk/comments/1kt4ut0/crosslisting_software_recommendations/) asks about disconnections and avoiding double sales; this is evidence of an objection, not permission to advertise Lane's unfinished delisting.

## Technical launch checklist

- Keep free staging **noindex**, including robots/header/meta, until a deliberate canonical-indexing decision. Organic search visits to staging should be forecast as zero. A custom domain is deferred, not a purchase task now.
- After domain ownership later: choose one HTTPS origin, update environment/canonical/social URLs and OAuth, redirect old hostname where feasible, set PUBLIC_INDEXING deliberately, verify robots and submit canonical sitemap to Search Console. Do not index both hosts.
- Existing unique public titles/descriptions, sitemap, canonical/social metadata, useful internal links and genuine 404 were locally tested. Recheck hosted HTTP/robots before Search Console submission. Account/devices/API/auth remain non-indexable.
- Homepage → features/how-it-works/pricing/download/help/security; tutorial → relevant workflow and field help; pricing → trial/signup with Windows requirement. No orphan acquisition page, keyword-stuffed footer or duplicated comparison template.
- Use actual product screenshots with descriptive alt text, responsive image sizes, readable captions, reduced unnecessary JS and stable layout. Capture hosted speed/cold-start evidence; do not label local QA as live or invent search performance.
- Organization/WebSite/SoftwareApplication schema only if factual. No fabricated ratings/reviews or LocalBusiness map. [Google's current documentation updates](https://developers.google.com/search/updates) say FAQ rich results stopped appearing on 7 May 2026 and the documentation was removed in June. Older government/health-only eligibility advice is now outdated. Visible FAQ remains useful to people; do not add FAQ schema to chase a retired result type.
- Search Console: owner verification after public host access, inspect canonical pages, submit sitemap, monitor genuine queries/clicks/indexing weekly. No paid SEO tools, bought backlinks or mass-generated articles.

Priorities after usable launch: one accurate workflow guide → answer repeated pilot questions → build one proven marketplace transfer page → publish a measured comparison only when useful. Later clusters: crosslisting, Vinted/eBay tutorials, inventory operations, pricing/profit once implemented. Do not publish finance advice from unverified product roadmap.
