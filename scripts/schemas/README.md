# Render Blueprint schema

`render.json` is a pinned copy of Render's public JSON Schema, fetched 12 September 2026 from https://render.com/schema/render.yaml.json, as linked by https://render.com/docs/blueprint-spec.

Local validation uses Ajv's draft-2020-12 implementation, no provider login. Update this snapshot deliberately when reviewing a provider configuration change. Schema validity is not proof of account entitlements, resource availability or a successful Render deployment; those remain live checks.
